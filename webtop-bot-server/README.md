# הפעלת webtop-bot על שרת בענן

הקבצים כאן מתקינים את [webtop-bot](https://github.com/matana09/webtop-bot) על שרת לינוקס (Ubuntu) כך שירוץ 24/7:
עולה לבד אחרי אתחול, חוזר לבד אם נפל, ושולח לטלגרם:

- כל 10 דקות – שיעורי בית חדשים, הודעות בית ספר ואירועי משמעת
- 17:00 – סיכום יומי
- 19:00 – מערכת שעות למחר ומה להכניס לתיק

כל ילד = חשבון WEBTOP אחד + בוט טלגרם משלו. אפשר להוסיף כמה ילדים שרוצים על אותו שרת.

> הדרך הקלה: לתת לסוכן במחשב את `AGENT.md` – הוראות צעד-אחר-צעד עם `cloud-init.yaml` שמתקין הכל לבד ב-Oracle Cloud.

## 1. שרת
כל שרת Ubuntu 22.04 / 24.04 קטן מספיק (1GB זיכרון):
- **Oracle Cloud Free Tier** – חינם לתמיד (צריך כרטיס אשראי לאימות).
- **Hetzner / DigitalOcean** – כ-4–5$ לחודש, הכי פשוט.

## 2. בוט טלגרם לכל ילד
ב-@BotFather בטלגרם: `/newbot` → שם → מקבלים טוקן. חוזרים על זה לכל ילד.

## 3. התקנה
מתחברים לשרת ב-SSH, מעתיקים אליו את התיקייה `webtop-bot-server` ומריצים:

```bash
cd webtop-bot-server
```
```bash
sudo bash install.sh
```

## 4. הוספת ילד
```bash
sudo bash add-kid.sh noa
```
הסקריפט שואל טוקן, שם משתמש וסיסמה של WEBTOP ו-chat IDs, שומר אותם בקובץ `.env` מוגן על השרת בלבד, ומפעיל את הבוט.

בפעם הראשונה משאירים את ה-chat IDs ריק, שולחים לבוט `/myid`, ואז: `sudo bash allow-chat.sh noa <ID>` (אפשר כמה, מופרדים בפסיק).

## פקודות שימושיות
```bash
journalctl -u webtop-bot@noa -f
```
```bash
sudo systemctl restart webtop-bot@noa
```
```bash
sudo bash update.sh
```

## הערות
- השעות מתוקנות לשעון ישראל כל השנה (בגרסה המקורית ההתראות מגיעות שעה מוקדם בחורף).
- ההתחברות בשרת היא בשם משתמש וסיסמה. התחברות עם עוגייה מהדפדפן עובדת רק ב-Windows ולא נדרשת.
- חתימות הורים דרך הבוט לא יעבדו בשרת בלי הגדרה נוספת של כתובת HTTPS. כל השאר עובד.
