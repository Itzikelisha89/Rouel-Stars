# webtop-bot על שרת בענן – בוט טלגרם אחד לכל הילדים

מתקין את [webtop-bot](https://github.com/matana09/webtop-bot) על שרת Ubuntu (למשל Oracle Cloud Always Free) כך שירוץ 24/7.
בוט טלגרם **אחד** שולח עדכונים על **כל הילדים**, וכל הודעה מתחילה ב-🎒 ושם הילד:

- שיעורי בית, הודעות ומשמעת חדשים – תוך כ-10 דקות
- 17:00 – סיכום יומי
- 19:00 – מערכת שעות למחר

**הדרך הקלה:** לתת לסוכן במחשב את [`AGENT.md`](AGENT.md). הוא פותח את הבוט, את השרת החינמי ומגדיר הכל.

## איך זה בנוי
- `webtop-router` – התהליך היחיד שקורא הודעות מהבוט. עונה ל-`/start` עם מספר הצ'אט ורשימת הילדים.
- `webtop-bot@<ילד>` – תהליך לכל ילד (חשבון WEBTOP משלו). שולח התראות דרך אותו בוט ולא קורא הודעות.
- שעון ישראל כל השנה (בגרסה המקורית ההתראות מגיעות שעה מוקדם בחורף).

## התקנה ידנית
`cloud-init.yaml` מדביקים ביצירת השרת ב-Oracle (מתקין לבד), או על שרת קיים:
```bash
sudo bash install.sh
```
```bash
sudo set-bot
```
```bash
sudo add-kid kid1
```
```bash
sudo allow-chat <chat-id>
```

## פקודות
| פקודה | מה עושה |
|---|---|
| `sudo set-bot` | טוקן הבוט המשותף |
| `sudo add-kid kid1` | הוספת ילד / שינוי סיסמה |
| `sudo allow-chat 111,222` | מי מקבל את העדכונים |
| `sudo webtop-update` | עדכון לגרסה האחרונה |
| `journalctl -u webtop-bot@kid1 -f` | לוג של ילד |

חתימות הורים ותפריט אינטראקטיבי לא זמינים בבוט המשותף – הוא מיועד להתראות.
