# 🀄 דומינו חמישיות (All Fives)

משחק דומינו אונליין ל-2 עד 4 שחקנים, עם צ'אט, בעברית. כל הנחה שבה סכום הקצוות הפתוחים מתחלק ב-5 שווה נקודה על כל 5 (15 על הלוח = 3 נקודות). משחקים עד 51.

## איך זה עובד
1. נכנסים לאתר, בוחרים שם ודמות ולוחצים **צור שולחן חדש**.
2. שולחים לחברים את הקישור (יש כפתור וואטסאפ) – הם נכנסים, בוחרים שם ומתיישבים.
3. המארח בוחר אם לשחק בזוגות ולוחץ **התחל משחק**. לכל שחקן 30 שניות לתור.

## מה יש בפנים
- 7 אבנים לכל שחקן (בארבעה – כל האבנים, בלי קופה). ביד הראשונה פותח 6:6, ואם היא בקופה – 5:5.
- **חייבים להגיד!** הנקודות לא נכנסות לבד – אחרי כל הנחה מכריזים כמה יש על הלוח (כפתור או מספר בצ'אט). השחקן הבא התחיל ולא אמרת? הנקודות הלכו.
- חוקי All Fives מלאים: ספינר עם 4 כיוונים, כפולה בקצה נספרת כפול, שליפה מהקופה, פאס, חסימה, סוף יד עם עיגול ל-5.
- 2, 3 או 4 שחקנים, או 4 בזוגות (שותפים מול שותפים).
- צ'אט עם בועות דיבור ליד השחקן, משפטים מהירים, תגובות אימוג'י, "מקליד…".
- תחושת שולחן: ההכרזות נאמרות בקול, דפיקה על השולחן בפאס, רואים את היריב מושיט יד לאבן, ערבוב לפני חלוקה, חותמת "דומינו!", ודף ניקוד בכתב יד (לחיצה על הניקוד למעלה).
- צלילים של אבנים על השולחן, אנימציות, ויברציה והתראה כשהתור שלך.
- רענון הדף או ניתוק → חוזרים לאותו כיסא. שחקן שעוזב → המחשב משחק במקומו.
- צופים: מי שנכנס כשהשולחן מלא צופה במשחק.

## הרצה מקומית
```bash
npm install
npm start          # http://localhost:3000
npm test           # בדיקות מנוע המשחק
```

## העלאה לאינטרנט (חינם, ב-Render)
1. היכנס ל-https://render.com והתחבר עם GitHub.
2. **New → Blueprint** ובחר את הריפו הזה (הקובץ `render.yaml` כבר מגדיר הכל).
3. אחרי כדקה תקבל כתובת כמו `https://domino-hamishiyot.onrender.com` – זה הקישור לשלוח לחברים.

> בשכבה החינמית השרת "נרדם" אחרי 15 דקות בלי שימוש, והכניסה הראשונה לוקחת כחצי דקה. משחקים פעילים נשמרים בזיכרון – הפעלה מחדש של השרת מאפסת אותם.
