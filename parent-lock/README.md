# ParentLock: נעילת המחשב מהטלפון דרך טלגרם

## מה זה עושה

- **🔒 נעל**: הילדים מקבלים הודעה על המסך, ואחרי דקה הם מנותקים מהמחשב. החשבון שלהם **מושבת**, כך שגם אם הם יודעים את הסיסמה Windows לא יכניס אותם. **האינטרנט נחסם** לגמרי (חוץ מטלגרם, כדי שתוכל לפתוח מרחוק).
- **🔓 פתח**: החשבונות והאינטרנט חוזרים.
- **⏱ חצי שעה / שעה**: המחשב נפתח ונועל את עצמו בסוף הזמן. הילדים מקבלים אזהרה 5 דקות לפני. הטיימר עובד גם בלי אינטרנט.
- **🚫 חסום אינטרנט**: רק האינטרנט נחסם, ואפשר להמשיך להשתמש במחשב (שיעורי בית, משחקים בלי רשת).
- **📊 מצב**: מראה מי מחובר ומה המצב.
- כשהמחשב נדלק או כשילד נכנס לחשבון, אתה מקבל הודעה.
- `/msg טקסט` מקפיץ הודעה על המסך של הילדים.

## התקנה (פעם אחת לכל מחשב)

### שלב 1: יוצרים בוט בטלגרם (לכל מחשב בוט נפרד)
1. בטלגרם מחפשים את **@BotFather** ולוחצים Start.
2. שולחים `/newbot`.
3. נותנים לבוט שם, למשל `מחשב סלון`.
4. נותנים שם משתמש באנגלית שנגמר ב-bot, למשל `elisha_salon_pc_bot`.
5. BotFather שולח **טוקן** (שורה כמו `123456789:AAH...`). שומרים אותו, הוא נדרש בהתקנה.

למחשב השני חוזרים על אותו תהליך ויוצרים בוט נוסף, למשל `מחשב חדר ילדים`.

### שלב 2: מתקינים על המחשב
1. מורידים את התיקייה `parent-lock` (קובץ ZIP) למחשב ו**מחלצים** אותה (קליק ימני ← "חלץ הכל").
2. לוחצים פעמיים על **install.bat** ומאשרים "כן" בחלון ההרשאות.
   אם מופיע חלון כחול של Windows SmartScreen: "מידע נוסף" ← "הפעל בכל זאת".
3. עונים על השאלות. הן באנגלית, כי חלון הפקודות לא מציג עברית:
   - **שם המחשב**: איך הוא ייקרא בטלגרם.
   - **הטוקן**: מדביקים את הטוקן מ-BotFather.
   - **Start בבוט**: פותחים בטלפון את הבוט החדש, לוחצים START, ואז Enter במחשב.
   - **חשבונות הילדים**: מקלידים את המספרים של החשבונות של הילדים.
   - **חשבון הורה סודי**: מכיוון שהילדים יודעים את הסיסמה, ההתקנה תציע ליצור חשבון מנהל חדש (`Parent`) עם סיסמה שרק אתה יודע. **חשוב לא לגלות להם אותה!** מהחשבון הזה מתקינים תוכנות ומשנים הגדרות.
4. בסוף ההתקנה תגיע הודעה בטלגרם "💻 ... נדלק" ויופיעו כפתורים בתחתית הצ'אט.

## חשוב לדעת

- **הילדים לא יכולים להיות מנהלים במחשב.** ההתקנה מורידה להם את הרשאות המנהל. אחרת הם יכולים פשוט למחוק את התוכנה.
- בזמן נעילה האינטרנט חסום **לכל המחשב**, כולל לחשבון ההורה. כדי לגלוש מהמחשב, לוחצים על "פתח".
- אם הילדים מנתקים את הכבל או את ה-Wi-Fi, הנעילה נשארת בתוקף, ופשוט לא תוכל לפתוח מרחוק עד שהחיבור יחזור.
- הודעות שנשלחו לבוט בזמן שהמחשב היה כבוי (לפני יותר מ-10 דקות) לא מבוצעות.
- רק מי שלחץ Start בבוט בזמן ההתקנה יכול לשלוט במחשב. כל אחד אחר שכותב לבוט נדחה.

## עדכון / הסרה
- **עדכון**: מריצים שוב את `install.bat` ועונים "Y" ל"Keep the current settings".
- **הסרה**: מריצים את `uninstall.bat`. החשבונות והאינטרנט נפתחים והתוכנה נמחקת.
- קובץ יומן לבדיקת תקלות: `C:\ProgramData\ParentLock\log.txt` (נגיש רק מחשבון מנהל).
