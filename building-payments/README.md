# בית וגן 6 · ניהול גבייה וחתימות

מערכת פרטית ומאובטחת לניהול התשלומים ודפי החתימה של 12 הדיירים בפרויקט המבנה המסוכן, רחוב בית וגן 6, בת ים.

- כניסה עם סיסמה (עוגיית HttpOnly חתומה, נעילה אחרי 6 ניסיונות כושלים, רישום יציאה בהחלפת סיסמה)
- תרשים בניין אינטראקטיבי: כל דירה צבועה לפי מצב (הושלם / בתהליך / טרם החל)
- לכל דירה: פרטי דייר, תשלומים (צ׳ק, העברה, מזומן, ביט/פייבוקס) עם צילום, דף חתימה עם צילום, סימון "נמסר לקבלן"
- דוח מודפס לקבלן, ייצוא CSV לאקסל, תזכורת בוואטסאפ, מצב כהה
- נתונים וקבצים ב-Netlify Blobs, נגישים רק דרך ה-API המאובטח

## פריסה (Netlify)
- תיקיית בסיס: `building-payments`, פרסום: `public`, פונקציות: `netlify/functions`
- משתנה סביבה חובה: `ADMIN_PASSWORD` (הסיסמה הראשונית; אפשר להחליף מתוך המערכת בהגדרות)

## הרצה מקומית
```
npm install
ADMIN_PASSWORD=test1234 node dev-server.mjs
```
