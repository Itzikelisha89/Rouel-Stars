# האבטאר האישי: תוכנית חינמית

המטרה: אבטאר שמדבר בקול שלך, נראה כמוך וחושב כמוך. כל הרכיבים חינמיים ורצים על המחשב שלך.

## המחשב
ELISHA: מעבד i9-14900HX, כרטיס RTX 4060 Laptop עם 8GB, זיכרון 64GB RAM, Windows.

## הרכיבים
| שכבה | כלי | איפה רץ |
|---|---|---|
| מוח | **Claude** דרך Claude Code שכבר מותקן אצלך (`claude -p`) | המחשב, על המנוי הקיים |
| קול | Chatterbox Multilingual + Phonikud (עברית) | המחשב. אימון (fine-tune) על Kaggle |
| תמונה | FLUX עם LoRA אישי (FluxGym) | אימון על Kaggle, יצירה במחשב (ComfyUI) |
| וידאו | LatentSync 1.5 או MuseTalk לסנכרון שפתיים, LivePortrait להבעות | המחשב |
| וידאו מתקדם | InfiniteTalk דרך Wan2GP | המחשב (איטי) |

## איך הכול מתחבר
```
שאלה או נושא
   ↓
Claude + persona.md  →  טקסט בסגנון שלך
   ↓
Chatterbox (הקול שלך)  →  קובץ WAV
   ↓
LatentSync על סרטון בסיס שלך  →  סרטון MP4 שבו אתה מדבר
```

## שלבים
0. **איסוף:** הקלטות לפי `recording-script.md`, תמונות ווידאו לפי `capture-checklist.md`, שאלון לפי `persona-questionnaire.md`.
1. **קול:** בדיקה ראשונה בלי אימון (שיבוט מ-10 שניות), אחר כך אימון על כל ההקלטות.
2. **תמונה:** אימון LoRA על 20 תמונות.
3. **וידאו:** סנכרון שפתיים על סרטון הבסיס.
4. **מוח:** בניית `persona.md` מהשאלון והטקסטים שלך, וחיבור הכול לסקריפט אחד.
5. **בדיקה עיוורת** מול חברים, ושיפור של מה שמסגיר.

## כללים
- הקבצים הגולמיים (קול, פנים, טקסטים פרטיים) נשמרים **רק במחשב שלך**. הם לא נכנסים ל-GitHub.
- תוכן שמתפרסם ברשתות מסמנים כ-AI, לפי הכללים של הפלטפורמות.
- מילת קוד משפחתית: אם מישהו מתקשר "בקול שלך" ומבקש כסף או עזרה דחופה, שואלים אותו את המילה.
