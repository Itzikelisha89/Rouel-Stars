# MOR SHABAT – THE LEGEND OF LAHAV 🎬

סרטון יום הולדת קולנועי (טריילר הוליוודי) למור שבת – האיש שמאחורי כל הציוד של גדוד להב.

**אורך:** כ-3:30 · **פורמט:** 4K (3840×2160), 16:9, 30FPS + גרסת גיבוי Full HD · **שפה:** עברית מלאה, קריינות + כתוביות RTL

## מה יש בפרויקט

| קובץ | תפקיד |
|---|---|
| `config.json` | **כל הטקסטים, הקריינות והתמונות** – זה הקובץ לעריכה |
| `assets/photos/` | התמונות של מור והמשפחה (01–10) |
| `assets/fonts/` | גופנים מקומיים (Heebo, Frank Ruhl Libre, Secular One, Cinzel, Orbitron) |
| `film.js` | מנוע הסרט – כל הסצנות, האפקטים והאנימציות (Canvas, דטרמיניסטי לפי זמן) |
| `index.html` | נגן תצוגה מקדימה + עורך טקסטים חי |
| `tools/voice.py` | קריינות בעברית (edge-tts, קול Avri) + תזמון משפטים לכתוביות |
| `tools/soundtrack.py` | ציר הזמן לפי אורך הקריינות, מוזיקה מקורית מסונתזת, אפקטים, מיקס |
| `tools/render.js` | רינדור פריים-פריים בכרום ← MP4 עם ffmpeg |
| `build/` | פלטים: `timeline.json`, `soundtrack.wav`, קבצי הקריינות וה-MP4 |

## מבנה הסרט

1. **פתיחה** – מסך שחור, פעימות לב, רדיו, ברק; "יש אנשים שמנהלים משימות…", מעבר במחסן ציוד תלת-ממדי, שקט, "הופך את הבלתי אפשרי לאפשרי", פיצוץ אור וכותרת זהב **MOR SHABAT – THE LEGEND OF LAHAV**.
2. **האיש והאגדה** – מור בשוט גיבור עם כרטיס שם, גאג החיפוש עם פנס, **"איפה מור?!"**, המחסן הופך להולוגרמה עם קופסאות שנפתחות, **MOR SYSTEM – EVERYTHING UNDER CONTROL**, ומערכת **MOR.AI** ש"מנהלת את כל הציוד בעולם" – ומתקשרת למור כשמבקשים ממנה פנס.
3. **LEVEL UP** – ספירה 5…1, המסך מתנפץ, MISSION UPDATED, מסוקים, זיקוקים, **HAPPY BIRTHDAY MOR SHABAT!**
4. **הברכה** – פסנתר ומיתרים, תמונות משפחתיות במסגרות זהב, כתוביות מסונכרנות לקריינות (בריאות, אושר, עושר, אהבה…).
5. **פינאלה** – חלקיקי זהב יוצרים את השם "מור שבת" בסיבוב תלת-ממדי, **ספירה 10…1 לכל האולם**, "מזל טוב מור שבת!" עם זיקוקים וקונפטי, כותרת סיום עם תמונת המשפחה, ולוגו סיום.

## הרצה

דרישות: Node 18+, Python 3 עם `numpy scipy edge-tts`, ffmpeg, Playwright + Chromium.

```bash
pip install numpy scipy edge-tts
npm run audio        # קריינות + מוזיקה + ציר זמן (צריך אינטרנט לקריינות)
npm run preview      # פתחו http://localhost:8080 – נגן עם סאונד, דילוג בין סצנות, מסך מלא (מקש f)
npm run render       # 4K + Full HD אל build/  (~25 דקות על 4 ליבות)
npm run render:hd    # רק Full HD (מהיר פי 3–4)
npm run stills -- 12,45.5,190   # תמונות בדיקה לזמנים מסוימים
```

## עריכה

- **טקסטים על המסך** – בנגן התצוגה פתחו "עריכת טקסטים", השינויים מוצגים מיד. "הורדת config.json" שומרת אותם; החליפו את הקובץ והריצו `npm run build`.
- **קריינות** – ערכו את `vo` ב-`config.json` (אפשר להוסיף `"say"` עם ניקוד כשההגייה לא מדויקת), והריצו `npm run audio`. אורך הסצנות מתעדכן אוטומטית לפי אורך הקריינות.
- **תמונות** – החליפו קבצים ב-`assets/photos/` או שנו את השיוך ב-`photos` ב-`config.json`. `fx`/`fy` = נקודת המיקוד (0–1) בתמונה, `zoom` = הגדלה.
- **מוזיקה** – כל המוזיקה נוצרת ב-`tools/soundtrack.py` (אקורדים, טמפו ועוצמות לפי חלקים). אפשר להחליף בקובץ מוזיקה מורשה משלכם ולערבב אותו במקום `MUS`.

## זכויות ושקיפות

- המוזיקה והאפקטים מסונתזים מאפס בקוד – מקוריים לחלוטין, מותרים להקרנה באירוע.
- הקריינות: קול עצבי של Microsoft (he-IL-AvriNeural) דרך edge-tts – זו קריינות TTS, לא קריין אנושי.
- הסצנות הן אנימציה סינתטית (מחסן, ממשקים, מסוקים, זיקוקים) – לא תיעוד אמיתי. אין בסרטון מידע מבצעי, צילומי בסיסים או ציוד אמיתי. הלוגו "LAHAV" הוא עיצוב מקורי ולא סמל רשמי.
- לא נעשה שימוש בכלי וידאו AI לשינוי פני מור – התמונות מוצגות כפי שהן, עם תנועת מצלמה, תאורה ודירוג צבע.
