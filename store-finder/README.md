# 📍 מוצא המוצרים — Store Finder

פלטפורמה לחנויות: בעל החנות מצייר מפה ומצלם מדפים, AI מזהה את המוצרים, והלקוח סורק QR בכניסה, מחפש ("סיר קטן") ורואה **תמונה של המוצר + המדף מסומן על המפה + מסלול הליכה מהכניסה**.

## הרצה

```bash
cd store-finder
npm install
export GEMINI_API_KEY=...              # לא חובה: זיהוי מוצרים מתמונות בחינם (Google AI Studio)
npm start                              # http://localhost:3000
```

דרישות: Node.js 22.13 ומעלה (משתמש ב-SQLite המובנה ב-Node, בלי מסד נתונים חיצוני).

| משתנה | ברירת מחדל | תיאור |
|---|---|---|
| `PORT` | `3000` | פורט השרת |
| `GEMINI_API_KEY` | — | זיהוי מוצרים מתמונות עם Gemini Flash, במסלול החינמי של Google (מפתח מ-aistudio.google.com, בלי כרטיס אשראי) |
| `GEMINI_MODEL` | `gemini-flash-latest` | מודל Gemini |
| `ANTHROPIC_API_KEY` | — | חלופה בתשלום: זיהוי עם Claude (אם שני המפתחות קיימים, Claude קודם) |
| `CLAUDE_MODEL` | `claude-opus-5-5` | המודל לזיהוי תמונות והרחבת חיפוש |

**בלי אף מפתח הכל עובד**, חוץ מהזיהוי האוטומטי: המנהל מוסיף מוצרים ידנית (שם, תיאור חופשי, מחיר, מעבר, מדף, מילות חיפוש ותמונה), או מייבא קובץ אקסל. החיפוש בעברית לא צריך AI.
| `PUBLIC_URL` | כתובת הבקשה | הכתובת שתופיע ב-QR (למשל `https://find.example.com`) |
| `DATA_DIR` | `./data` | מסד הנתונים והתמונות |

## איך זה עובד

**בעל חנות** (`/`, ואז `/owner.html`):
1. **מפה** — רשת שבה כל משבצת ≈ מטר (ברירת מחדל 40×25 = 1000 מ״ר). גוררים כדי לצייר מדף/מעבר, נותנים שם, וממקמים את הכניסה.
2. **צילום מדף** — בוחרים את המדף שעומדים מולו ומצלמים. התמונה מוקטנת בטלפון, נשלחת ל-Claude Vision, וכל מוצר נשמר עם שם, מילות חיפוש, קומת מדף ומלבן בתמונה. **המיקום נקבע לפי המדף שנבחר**, ולכן הוא תמיד מדויק.
3. **מוצרים** — ✨ מצלמים מוצר והמערכת ממלאת שם, תיאור ו-25 עד 40 מילות חיפוש (כל מה שלקוח עשוי לבקש: שימושים, גדלים, חומרים, חגים, שגיאות כתיב). הוספה ידנית מלאה (שם, תיאור חופשי, מחיר, מעבר, מיקום במדף, מילות חיפוש ותמונה של המוצר), עריכה, הסתרה מלקוחות (אזל מהמלאי) ומחיקה.
4. **QR ונתונים** — שלט להדפסה לכניסה, ורשימה של מה לקוחות חיפשו ולא מצאו.
5. **🔔 התראות** — מתעדכן לבד (עם צפצוף אופציונלי): לקוח שקרא לעובד ובאיזה מעבר, מדף ריק או מוצר שלא היה במקום, ומוצרים שלקוחות ביקשו שנביא (עם טלפון לחזרה).
6. **📊 דוח פיילוט** — לקוחות ייחודיים וחוזרים, אחוז שמצאו את המוצר, זמן עד המוצר, שעות עבודה שנחסכו, שעות עומס, שימוש יומי, מוצרים בעייתיים ובקשות. מודפס כ-PDF להנהלה.

**לקוח** (`/s/<כתובת-החנות>`): חיפוש בטקסט או בקול. החיפוש מבין עברית: מתעלם מניקוד ומאותיות סופיות, מוריד תחיליות (ה/ו/ב/ל/מ/ש/כ) וסיומות רבים, וסובל שגיאת כתיב של אות אחת. אם לא נמצא כלום, Claude מציע מילים נרדפות ומחפש שוב.
- **📚 מילון מילים נרדפות מובנה (חינמי, בלי AI)** — "קדרה" או "משהו לבשל מרק" מוצאים סירים, "ילקוט" מוצא תיקי גב. נמצא ב-`synonyms.js` וקל להוסיף לו מילים.
- **📷 חיפוש לפי תמונה** — הלקוח מצלם מוצר (או תמונה ממודעה/וואטסאפ) והמערכת מוצאת אותו בחנות. דורש מפתח GEMINI_API_KEY חינמי.
- **🛒 רשימת קניות עם מסלול** — מוסיפים כמה מוצרים, והמערכת מסדרת אותם לפי המסלול הקצר בחנות, עם עצירות ממוספרות על המפה.
- **✅ מצאתי / ❌ לא מצאתי** — כל לקוח הופך לבודק מדפים: מדף ריק או מוצר שזז מגיעים מיד למסך ההתראות.
- **📣 בקשו שנביא** — כשמוצר לא קיים בחנות, הלקוח משאיר בקשה (וטלפון, אם רוצה).
- **🙋 קריאה לעובד** — עובד מקבל התראה עם המעבר שבו הלקוח עומד.

**ריבוי חנויות**: כל חנות נרשמת עם כתובת משלה, וכל הנתונים מופרדים לפי חנות.

## מבנה הקוד

```
server.js        API (Express) — חשבונות, מפה, תמונות, מוצרים, חיפוש ציבורי, QR
db.js            סכמת SQLite
ai.js            Claude: זיהוי מוצרים בתמונה (structured outputs) + הרחבת חיפוש
search.js        מנוע חיפוש עברי
insights.js      ביקושים עונתיים (חגים, מגמות)
synonyms.js      מילון מילים נרדפות לחנות כלי בית
pilot.js         דוח פיילוט (מבקרים, הצלחה, זמן עד המוצר, זמן עבודה שנחסך)
public/          ממשק (HTML/JS בלי build): index, owner, customer
public/js/map.js ציור מפה ב-SVG, מסלול קצר (BFS), חיתוך תמונת מוצר
test/            npm test
```

## השלבים הבאים

- חיבור למערכת הקופה/המלאי (ייבוא Excel/CSV) כדי לסנכרן מוצרים ומחירים
- מדבקות QR בכל מעבר ("אתה כאן") לניווט מהמיקום הנוכחי
- שפות נוספות (ערבית, רוסית, אנגלית)
- אחסון תמונות בענן (S3/R2) ו-Postgres לפריסה בקנה מידה גדול
- תשלום חודשי לחנויות (מנויים)
