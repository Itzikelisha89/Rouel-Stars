# ROI DROR – סרטון יום הולדת 🎬

סרטון של 90 שניות לרועי דרור, מג״ד שבא לכבוש את העולם: יום הולדת עד 120, המשפחה שגדלה ודרגת אל״מ בדרך.

**פורמט:** 1080×1920 (9:16, מסך מלא בטלפון), 30FPS, H.264 + AAC. נבנה לוואטסאפ.
**קבצים מוכנים:** `build/ROI_DROR_WhatsApp.mp4` לשליחה, `build/ROI_DROR_FullHD.mp4` לגרסת מאסטר.

## מבנה הסרט

| זמן (בערך) | חלק | מה רואים |
|---|---|---|
| 0–13 | פתיחה | "יש אנשים שמחכים שהעולם ישתנה… ויש אנשים שיוצאים לכבוש אותו", פיצוץ אור וכותרת זהב **ROI DROR – THE COMMANDER** |
| 13–31 | האגדה | 2006 "כאן הכל התחיל" עם תמונת הטירונות, רועי גזור כגיבור עם תאורה זהובה, התגיות "מפקד · לוחם · גיבור", הטקס והדיוקן על הקיר: "משאיר חותם" |
| 31–43 | מאחורי הקלעים | אוטובוס (סוללה 3%), חוף (מנוחת לוחמים), יום ההולדת: "אין לאן לברוח!" |
| 43–55 | עדכון משימה | HUD: "המשפחה גדלה, +1 בקרוב", כותפת שמקבלת עלה שלישי: **אל״מ – הדרגה בדרך** |
| 55–76 | הברכה | פסנתר ומיתרים, תמונות במסגרות זהב, בריאות, אושר ונחת |
| 76–90 | פינאלה | **עד 120!** עם זיקוקים, HAPPY BIRTHDAY ROI DROR, תמונת סיום וקרדיט |

כל המשפטים מופיעים גם ככתוביות, כי בוואטסאפ הרבה צופים בלי סאונד.

## הקול: ElevenLabs

`tools/voice.py` מפיק את הקריינות בקול המשובט שלך ב-ElevenLabs. כשאין מפתח הוא נופל לקול גיבוי (edge-tts). הקול ששימש בפועל נכתב ב-`build/vo/ENGINE.txt`.

1. שמרו את המפתח כ-Network secret לשרת `api.elevenlabs.io`, בכותרת `xi-api-key`. בענן זה נעשה בהגדרות הסביבה, ומקומית במשתנה `ELEVENLABS_API_KEY`.
2. אם יש בחשבון יותר מקול משובט אחד, כתבו את שם הקול ב-`config.json` תחת `voice.elevenlabs_voice_name`.
3. מריצים `npm run audio && npm run render`. ציר הזמן נמתח אוטומטית כך שהסרט נשאר בדיוק 90 שניות.

## עריכה

- **קריינות:** `vo` ב-`config.json`. אפשר להוסיף `say` כשההגייה לא מדויקת (למשל "מַגַּד").
- **טקסטים על המסך:** `titles` ב-`config.json`, ואחריהם `npm run soundtrack && npm run render`.
- **תמונות:** `assets/photos/`. רועי הגזור נמצא ב-`assets/cutouts/roi_hero.png` (rembg, u2net_human_seg).
- **תצוגה מקדימה:** `npm run preview` ואז http://localhost:8080
- **אורך אחר:** `TARGET=60 npm run soundtrack`

## זכויות

המוזיקה והאפקטים מסונתזים מאפס בקוד (`tools/synth.py`, `tools/soundtrack.py`). התמונות הן של המשפחה והחברים ומוצגות כמו שהן, בלי שינוי פנים. בתמונת הגיבור רק הרקע הוסר. הכותפת והעלים הם איור מסוגנן, לא סמל רשמי.
